# Blue & Black Portfolio

## Run it in Visual Studio Code
1. Extract `blue_black_portfolio.zip`.
2. Open the extracted `blue_black_portfolio` folder in Visual Studio Code.
3. Open `index.html`.
4. If you have the **Live Server** extension, right-click `index.html` and select **Open with Live Server**. Otherwise, double-click `index.html` to open it in your browser.

## Personalise it before publishing
- Update your name and bio in `index.html` if needed.
- Replace the BR avatar placeholder with a real photo if you want (the current one is a CSS design, so no image file is needed).
- Update the project cards so they accurately represent your work.
- In `script.js`, replace `YOUR_EMAIL@example.com` with the email address you want to receive enquiries at.
- Update social links or add a CV link if you want them included.

The portfolio uses HTML, CSS and JavaScript only. Google Fonts requires an internet connection; the page still works without it using fallback fonts.
